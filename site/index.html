Questions

Which apps does it work with?

Anything with a text field: T3 Code, Claude, Codex, Claude Code, Cursor, ChatGPT, your terminal, Mail, Messages, Notes. If you can type there, you can talk there.

Will it run on my Mac, and in my language?

Any Mac with an Apple chip, M1 or newer, on macOS 26 or later; the benchmarks are taken on an M1, so every newer chip is faster. It understands the 25 European languages of Parakeet, among them English, German, French, Spanish, Italian, Portuguese, Dutch, Polish and Ukrainian, and detects the language as you speak.

Option+Space is already my Alfred or Raycast shortcut. What now?

Record another key in Settings, General, Keyboard Shortcuts: any combination works, a single key such as Right Command too. Option+Space is only the default because no macOS shortcut owns it.

Why does Pladder ask for Accessibility?

To paste for you: macOS lets an app press ⌘V in another app only with Accessibility. Without it, Pladder still works and leaves the text on the clipboard for you to paste. To learn your corrections it reads only the words it pasted and a little around them, and keeps nothing.
